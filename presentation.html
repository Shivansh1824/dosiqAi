The "Zero-Waste" Architecture

How we built a medication app that scales to 1 lakh users with 90% less database cost and zero lag.

The Problem

If 1 lakh users open their calendar 10 times a day, that's **1 Million API calls** to our database. If we pay per request, we eventually go bankrupt. Plus, the app feels slow if it has to fetch data every time you tap a date.

01. The Solution Blocks

🧠

The "Math Student"

Instead of asking the database if a medicine is due, the phone's CPU does the math locally. It knows your schedule (e.g., Every 2 days) and calculates the result instantly.

"Like a student who knows the multiplication table instead of using a calculator for every move."
🛒

The "Bulk Shopper"

We don't buy one egg at a time. When you open the app, we fetch 14 days of logs at once. As you scroll, the app is already ready.

"Like buying a whole carton of eggs on Sunday so you don't have to go to the shop every morning."
🚀

The "Fast Waiter"

When you tap "Taken", the UI turns green instantly. We don't wait for the server's reply. We sync it in the background while you keep using the app.

"Like a waiter who says 'Coming right up!' before they've even reached the kitchen."
⚖️

The "Weekly Audit"

Once a week, the app checks the cloud and its local math to make sure everything matches. If there's a drift, it auto-corrects.

"Like a bank clerk who counts the physical cash every Friday to make sure it matches the computer."

90.2%

Reduction in Database Costs & API Usage

02. The Mathematical Brain

📅

Daily & Weekly

Simple checks: "Is it within the start/end date?" and "Is it Monday?" This handles 70% of meds instantly.

if (today == Monday) { showMed(); }
🔢

Interval Days (Cycles)

For complex meds (e.g., Every 3 days), we use the **Modulo** trick. We count the days since the start and see if the remainder is zero.

if (daysSinceStart % 3 == 0) { showMed(); }
"Like checking if the current day is a 'multiple of 3' on a giant invisible ruler."

03. The Journey of a Tap

1
Instant UI Update (0ms)

The moment you tap "Take," the screen turns green. No waiting for the internet. Total "wow" factor for the user.

2
OS Notification Intercept

The app immediately tells the phone: "Delete the 8:00 AM alarm for Paracetamol!" This prevents annoying double-notifs if taken early.

3
Background Cloud Sync

Offline? No problem. The app saves the 'Taken' status locally and waits for the internet to talk to Supabase. It's Bulletproof.

4
Weekly Reconciliation

Every week, the system double-checks: "Does the phone's math match the database's record?" This is our 'Source of Truth' audit.

04. Why this is a Win

💰 Huge Savings

By preventing "Waste Calls" on empty calendar days, we save thousands of dollars as the user base grows.

🏎️ Instant Speed

The user never sees a loading spinner when clicking the calendar. It feels like a high-end premium app.

🔔 Safe Reminders

Taking a med early cancels only THAT specific reminder. Other medicines remain active and safe.

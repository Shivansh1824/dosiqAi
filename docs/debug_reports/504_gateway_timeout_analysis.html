Technical Incident Report: API 504 Gateway Time-out

Date: April 11, 2026

Component: Mobile App (Frontend) & Custom VPS API (Backend)

Issue Tracking: 504 Gateway Time-out during AI Document Analysis.

1. Executive Summary

When users upload complex PDF documents (like prescriptions or lab reports) for AI analysis, the mobile application actively loops in the backend VPS API endpoint (/functions/v1/document-manager). However, because extracting and structuring data using AI (Gemini) is a high-latency operation, the remote AI processing consistently exceeds 60 seconds to complete.

The Problem: The NGINX web server hosting the VPS custom domain enforcing the API (api.dosiqai.com) has a strict default 60-second connection timeout (proxy_read_timeout). At exactly 60 seconds, NGINX forcefully terminates the client connection, throwing a 504 Gateway Time-out HTML error page to the mobile app.

2. The Disconnect Phenomenon

Despite the proxy explicitly dropping the connection to the mobile application, the custom backend API does not stop processing the document. The backend script securely continues operating in the background, completes the exact AI parsing 10 to 20 seconds later, and successfully writes the AI payload directly to the PostgreSQL database.

Because the mobile app frontend previously relied on a synchronous HTTP response to update its UI, the dropped connection caused the app to trap an error. This prevented the app from rendering the newly populated AI data that was just successfully generated on the backend.

3. Required Action & Approval Request

A permanent networking fix requires standard server administration to align HTTP capacities with AI workloads.

Proposed Solution: Increase VPS Proxy Timeout to 120s+

Since the initial premature disconnect strictly originates from the NGINX proxy on the VPS, updating the location block in the NGINX configuration to allow extended processing time will restore synchronous harmony.

location / {
    proxy_read_timeout 300s;
    proxy_connect_timeout 300s;
    proxy_send_timeout 300s;
    # ... existing configuration
}

We kindly request approval to standardize the VPS NGINX configurations to support long-polling AI tasks.

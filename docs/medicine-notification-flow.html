Technical Implementation Details

🔔 Notification ID Strategy

All notifications for a single medicine reminder use the same notification ID. This prevents notification pile-up in the drawer—each new notification replaces the previous one, maintaining a clean notification tray.

⚙️ Background Reliability

Utilizes Notifee's TimestampTrigger with Android's alarmManager to ensure notifications fire reliably even when the app is completely killed or in the background. No dependency on app lifecycle.

🔐 Required Permissions

SCHEDULE_EXACT_ALARM: Required for Android 12+ to schedule precise notifications
USE_FULL_SCREEN_INTENT: Enables full-screen notification takeover on locked devices

👆 User Interaction Handling

When a user clicks "Taken" or "Snooze", the system immediately cancels all pending scheduled notifications for that specific reminder, preventing duplicate or outdated notifications from appearing.

📱 Adaptive Display Logic

Full-screen notifications intelligently adapt based on device state: full takeover when locked for maximum visibility, persistent heads-up when unlocked to avoid disrupting active work.

🎯 Notification Priority

All notifications use high importance level to ensure visibility. Persistent heads-up notifications remain at the top of the screen when unlocked, providing constant visibility without auto-dismissal.

Key Benefits

🎯

Non-Intrusive Design

Persistent heads-up notifications stay visible at the top of the screen without blocking content or interrupting active work. Users can continue their tasks while remaining aware of medication reminders.

⚡

Urgent Escalation

Full-screen takeover on locked or idle devices ensures critical medication reminders cannot be missed. The system escalates appropriately when the user is not actively using their device.

🎨

User Choice & Flexibility

Two distinct modes cater to different user needs: Standard mode for gentle reminders, Aggressive mode for critical medications. Customizable snooze durations provide additional personalization.

🚫

No Notification Spam

Smart notification replacement using the same ID prevents drawer pile-up. Users see only the most recent reminder, maintaining a clean notification experience without overwhelming clutter.

🔋

Background Reliability

Leverages Android's alarmManager for guaranteed notification delivery even when the app is killed. No battery drain from constant background processes—notifications are scheduled and fire independently.

✨

Intelligent Adaptation

Context-aware notification behavior adapts to device state. The system knows when to be gentle (unlocked, active use) and when to be urgent (locked, idle), optimizing for both adherence and UX.
